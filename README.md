# ItsAllGoodMan

- create a .env in src directory in the format
    ```
    MYSQL_HOST=<localhost>
    MYSQL_USER=<user>
    MYSQL_PASSWORD=<password>
    ```
- (OPTIONAL) create a python environment and use it.
- install requirement from requirements.txt
    ```bash
    pip install -r requirements.txt
    ```
    to run, first go to src 
    ```bash
    cd src
    ``` 
    and then run 
    ```bash
    streamlit run main_app.py
    ```
- Open the url given in a browser if it hasn't opened.
